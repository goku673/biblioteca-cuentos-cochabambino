# Imágenes necesarias

La aplicación utiliza las copias `.webp` optimizadas de estos archivos. Los
originales JPG y PNG se conservan como respaldo.

## Portada

- `portada-cultura.webp`
- `portada-tradiciones.webp`

## Mapa

- `mapa-cochabamba.webp`

## Provincias

- `provincia-cercado.webp`
- `provincia-ayopaya.webp`
- `provincia-tapacari.webp`
- `provincia-arque.webp`
- `provincia-bolivar.webp`
- `provincia-quillacollo.webp`
- `provincia-german-jordan.webp`
- `provincia-punata.webp`
- `provincia-campero.webp`
- `provincia-jose-carrasco.webp`
- `provincia-tiraque.webp`
- `provincia-mizque.webp`
- `provincia-esteban-arce.webp`
- `provincia-chapare.webp`
- `provincia-capinota.webp`
- `provincia-arani.webp`

Recomendación: usa imágenes horizontales de al menos 1200 × 800 px para las
provincias y 1600 × 900 px para la portada. El mapa debe ser PNG para conservar
su transparencia y calidad.
